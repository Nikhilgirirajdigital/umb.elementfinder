# Umb.ElementFinder Client

The **Element Finder** Backoffice UI is written in TypeScript + Lit and built with Vite.

## Commands

- `npm install` installs the development dependencies.
- `npm run typecheck` checks the TypeScript source.
- `npm run build` builds the client into `../wwwroot/App_Plugins/ElementFinder`.
- `npm run watch` watches and rebuilds the client.

The Umbraco Backoffice package is externalized by Vite so Umbraco's own runtime is used at runtime.
